# JumpAble

**JumpAble** ist ein 2D-Jump-and-Run-Spiel, das im Rahmen eines Schulprojekts an der HTL Krems entwickelt wird. Das Spiel wird mit dem MonoGame-Framework und der Programmiersprache C# umgesetzt.

Ein besonderer Schwerpunkt des Projekts liegt auf der **Barrierefreiheit (Accessibility)**. Das Spiel soll möglichst vielen Menschen ein angenehmes und zugängliches Spielerlebnis ermöglichen.

## 🎮 Features

- 2D-Jump-and-Run mit 1–3 spielbaren Leveln
- Steuerung der Spielfigur über die Tastatur
- Anpassbare Tastenbelegung
- Übersichtliche und leicht navigierbare Benutzeroberfläche
- Tastaturnavigation mit sichtbarer Fokusmarkierung
- Gute Lesbarkeit und ausreichende Farbkontraste (mindestens 7:1)
- Physik- und Kollisionssystem
- Lebenssystem für die Spielfigur
- Pause- und Einstellungsmenü

Weitere geplante Funktionen:
- Soundeffekte bei Spielinteraktionen
- Optional aktivierbare Zeitbegrenzung
- Sammelbare Münzen und bewegliche Gegner

## 🕹️ Steuerung

Die Standardsteuerung des Spiels:

| Taste | Funktion |
|---|---|
| A | Nach links bewegen |
| D | Nach rechts bewegen |
| Leertaste | Springen |

Die Tastenbelegung soll im Einstellungsmenü angepasst werden können.

## 💻 Voraussetzungen

Für die Entwicklung und Ausführung werden folgende Voraussetzungen benötigt:

- Windows 10 oder neuer
- .NET SDK (passende Version für das Projekt)
- MonoGame
- JetBrains Rider oder Visual Studio Code (für die Entwicklung)

## 🚀 Installation und Start

1. Repository herunterladen oder klonen:

   ```bash
   git clone <REPOSITORY-URL>
   ```

2. Das Projekt in JetBrains Rider oder Visual Studio Code öffnen.

3. Sicherstellen, dass das benötigte .NET SDK und MonoGame installiert sind.

4. Das Projekt starten:

   ```bash
   dotnet run
   ```
