# JumpAble
2D-Jump-and-Run-Spiel mit Fokus auf Accessability
Plan ist es, dass unter Einsatz das Monogame Frameworks ein Applikations basiertes Jump and Run Spiel erstellt wird, es ist nicht webbasiert. Eben genanntes Jump and Run soll viel Wert auf Accessibilty legen, wie beispielsweise guten Kontrast für Farbenblinde Menschen eine leicht zu navigierende UI, in den einzelnen Level, von denen wir 1 bis 3 geplant haben, möglichst keinen Text und variable Tastenbelegung.
